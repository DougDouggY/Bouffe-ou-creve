# Publications GitHub Pages — deux jeux indépendants

Cette branche héberge DEUX jeux : l'index racine (Bouffe ou Crève) et `duel-des-clochers/` (Les Convaincants).

Lors de TOUTE publication, partir du dernier HEAD distant `gh-pages`, puis remplacer UNIQUEMENT les fichiers du jeu concerné. Ne jamais vider la branche, utiliser un déploiement qui nettoie tous les fichiers, ni supprimer les autres dossiers. Conserver `.nojekyll`, cet AGENTS.md et `duel-des-clochers/` lors des mises à jour du jeu racine. Conserver `index.html` lors des mises à jour de Les Convaincants.

Avant de pousser, vérifier la liste complète des fichiers supprimés et s'assurer qu'aucun fichier d'un autre jeu n'est supprimé. Après le déploiement, contrôler les deux URL : `/Test/` et `/Test/duel-des-clochers/`.
